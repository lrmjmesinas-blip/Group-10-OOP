# **MotorPH Payroll System (OOP Version)**

## **Project Summary**

The MotorPH Payroll System is a Java-based Object-Oriented Programming (OOP) application developed to automate payroll processing, employee information management, attendance monitoring, leave balance tracking, and user authentication.

The system was redesigned from a procedural implementation into an OOP architecture that applies the principles of encapsulation, inheritance, polymorphism, and abstraction.

## **Features**

Authentication, Employee Management, Payroll Processing, Attendance Management, Leave Management, GUI Features

## **OOP Principles Applied**

**Encapsulation**: Sensitive employee and payroll data are encapsulated within classes using private fields and accessed through getter methods.

**Inheritance**: The Employee class serves as a base class for employee types.

**Polymorphism**: An Employee reference can point to different employee types.

**Abstraction**: Payroll computations ae separated into dedicated calculator classes.

## **How to Run the Project**

### Prerequisites

Java Development Kit (JDK) 17 or newer

Visual Studio Code

Java Extension Pack for VS Code

#### Procedure
1. Download the Project. Clone the repository to your local device.
2. Open the project in VS Code. Select project folder Group-10-OOP.
3. Verify that Java is installed. If not, install JDK 17 or newer.
4. Compile the project. In the VS code terminal, run: javac app/*.java model/*.java calculator/*.java service/*.java dao/*.java ui/*.java
5. Run the application. In the same terminal, run: java ui.Login
